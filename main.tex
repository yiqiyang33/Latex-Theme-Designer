\section{What This Repository Is / 这个仓库是什么}

This repository is a local-first LaTeX note template with a Toolkit UI.
You can tune styles, switch theorem modes, choose compile recipes, split files, and preview PDF from one place.\sidenote{Short reminders, page references, or local intuition fit well here.}

这个仓库是一个本地优先的 LaTeX 笔记模板，并带有 Toolkit UI。
你可以在同一套工作流中做样式调参、切换定理模式、选择编译配方、拆分文件并预览 PDF。

\section{Core Files / 核心文件职责}

\begin{itemize}
    \item \texttt{main.tex}: main entry document / 主入口文档。
    \item \texttt{theme.sty}: theme styles and color tokens / 主题样式与颜色 token 定义。
    \item \texttt{theorems.tex}: theorem + callout environments / 定理与提示框环境。
    \item \texttt{commands.tex}: custom commands / 自定义命令。
    \item \texttt{theme.overrides.tex}, \texttt{theme.colors.tex}, \texttt{theme.ui.json}: generated by Toolkit UI / 由 Toolkit UI 生成。
    \item \texttt{src/}, \texttt{assets/template/}: VS Code extension runtime and bundled starter assets / VS Code 扩展运行时代码与内置模板资源。
\end{itemize}

\section{Compile Paths / 编译路径}

\begin{itemize}
    \item Internal fallback pipeline / 内置回退管线：stable baseline without VSCode recipe dependency / 不依赖 VSCode recipe，作为稳定基线。
    \item VSCode recipe mode / VSCode 配方模式：
    reads workspace settings and recipe definitions from \texttt{.vscode/settings.json}.
    该模式会从 \texttt{.vscode/settings.json} 读取 tools 与 recipes。
\end{itemize}

If \texttt{.vscode/settings.json} is missing on a new machine,
use Toolkit UI button \texttt{Generate VSCode settings.json}.
It only creates the file when missing and never overwrites an existing one.

如果在新机器上缺少 \texttt{.vscode/settings.json}，请在 Toolkit UI 中点击
\texttt{Generate VSCode settings.json}。
该功能只会在文件不存在时创建，不会覆盖已有配置。

\chapter{Quick Start Tutorial / 快速上手教程}

\section{Step 1: Run Toolkit UI / 第一步：启动 Toolkit UI}

Open VS Code or Cursor, then run:

\begin{verbatim}
LaTeX Editing Toolkit: Open Toolkit
\end{verbatim}

Then open compile target and recipe controls in the webview panel.

然后在扩展面板中选择编译目标与 recipe，并根据需要调整 theme toggle 与颜色。

\section{Step 2: Save + Compile / 第二步：保存并编译}

Use \texttt{Save Overrides} to write
\texttt{theme.overrides.tex} and \texttt{theme.colors.tex},
then use \texttt{Compile PDF}.

点击 \texttt{Save Overrides} 会写入
\texttt{theme.overrides.tex} 和 \texttt{theme.colors.tex}，
随后点击 \texttt{Compile PDF} 即可编译。

\section{Step 3: Theorem Mode Toggle / 第三步：定理模式切换}

Toggle \texttt{Plain amsthm Theorem}:
\begin{itemize}
    \item OFF: styled tcolorbox theorem family / 关闭时：彩色盒子风格。
    \item ON: plain amsthm theorem family / 打开时：朴素 amsthm 风格。
\end{itemize}

Command signatures stay compatible in both modes.
两种模式下命令签名保持一致（例如 \texttt{\textbackslash thm\{title\}\{label\}\{body\}}）。

\section{Label Prefix Rule / 标签前缀规则}

The theorem commands keep automatic label prefix behavior with smart dedupe:

定理命令保留自动前缀并支持智能去重：
\begin{itemize}
    \item Empty label: no \texttt{\textbackslash label}.
    \item 空标签：不写 \texttt{\textbackslash label}。
    \item Raw label \texttt{foo} under \texttt{\textbackslash thm} becomes \texttt{thm:foo}.
    \item 对 \texttt{\textbackslash thm} 而言，裸标签 \texttt{foo} 会变成 \texttt{thm:foo}。
    \item Prefixed label \texttt{thm:foo} stays \texttt{thm:foo}.
    \item 已带前缀 \texttt{thm:foo} 会保持不变。
\end{itemize}

\section{Inline + Study Note Helpers / 行内与笔记辅助}

Inline helpers keep repeated note markup compact:
\begin{itemize}
    \item \texttt{\textbackslash key}: \key{key idea} / \key{关键想法}
    \item \texttt{\textbackslash term}: \term{technical term} / \term{术语}
    \item \texttt{\textbackslash warn}: \warn{watch this condition} / \warn{注意条件}
    \item \texttt{\textbackslash todo}: \todo{fill in the proof} / \todo{补全证明}
    \item \texttt{\textbackslash code}: \code{LaTeX Editing Toolkit: Open Toolkit}
\end{itemize}

这些行内命令可以让常见笔记标记更紧凑，也可以在 Toolkit UI 里调整颜色。

\insight{
Use \texttt{\textbackslash insight\{...\}} for a distilled idea that should stand out from routine exposition.
可以用 \texttt{\textbackslash insight\{...\}} 放置需要醒目的核心想法。
}

\pitfall{
Use \texttt{\textbackslash pitfall\{...\}} for common mistakes, hidden assumptions, or fragile steps.
可以用 \texttt{\textbackslash pitfall\{...\}} 标记常见错误、隐含假设或易错步骤。
}

\intuition{
Use \texttt{\textbackslash intuition\{...\}} for geometric pictures, informal explanations, or mental models.
可以用 \texttt{\textbackslash intuition\{...\}} 记录几何图像、非正式解释或心智模型。
}

\summary{
Use \texttt{\textbackslash summary\{...\}} for a local recap before moving to the next topic.
可以用 \texttt{\textbackslash summary\{...\}} 在进入下一主题前做局部总结。
}

\question{
Use \texttt{\textbackslash question\{...\}} for open questions or checks to revisit later.
可以用 \texttt{\textbackslash question\{...\}} 记录之后要回看的问题或检查点。
}
